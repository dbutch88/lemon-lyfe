# Lemon Lyfe

Kid crews, lemonade stands and turf wars. A multiplayer, phone-first strategy game.

**Play:** https://dbutch88.github.io/lemon-lyfe/

- `index.html` is the whole game (built file; don't edit by hand).
- `src/sugar-corners.html` is the game source, `src/ll_backend.js` connects it to Firebase.
- Rebuild with `cd src && python3 build_standalone.py firebase_config.json`.
